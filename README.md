# 汴灯 · 夜游汴京

一卷以宋韵为底色的沉浸式夜游网页。项目以《清明上河图》的城市意象为灵感，将汴河、虹桥、长街、水亭、宋词与灯火组合成五章连续场景；整体采用墨青、暖金与朱红配色，保留中国古风的留白与唯美感。

> 本项目是艺术化演绎，并非历史场景的精确复原。页面插图为 AI 创作，古典诗词原文属公有领域。

## 在线预览与本地运行

项目原生页面位于 `front/kaifeng-night-tour/`，不需要安装 npm 依赖，也不需要构建。

```bash
cd front/kaifeng-night-tour
python -m http.server 4173
```

浏览器访问：<http://localhost:4173/>

请通过 HTTP 服务打开，不要直接双击 `index.html`。Three.js 通过 jsDelivr CDN 加载，首次打开需要联网；建议运行在现代 Chrome、Edge、Firefox 或 Safari 浏览器中。

## 五章夜游

1. **水门初见**：从汴河水门入城，展开整卷夜景。
2. **虹桥灯渡**：滚动运镜至虹桥，行人沿拱桥缓步往来，可拾取桥边诗句。
3. **长街如昼**：浏览茶、绢、舟三种市井意象，体验打铁花、烟花与叫卖声。
4. **临水听诗**：阅读《青玉案·元夕》或《望海潮》，点选一句作为灯笺。
5. **万灯归河**：将选中的诗句寄于孔明灯或河灯。

页尾另有“重现一城”微缩建筑演出。顶部“白昼 / 夜色”按钮会同步切换场景灯光、配图和文案，并在本地记住主题选择。

## 操作方式

- **滚动页面 / 章节导航**：推进五章场景与镜头。
- **白昼 / 夜色**：切换昼夜主题。
- **拾起桥边的一句诗**：展开或收起桥边诗笺。
- **一盏茶 / 一匹绢 / 一叶舟**：切换市井观察文案。
- **打铁花 / 看烟花 / 听一声叫卖**：触发市集互动；语音使用浏览器语音合成能力。
- **点选诗句**：更新个人灯笺，再前往末章放灯。
- **放一盏灯 / 放一盏河灯**：生成携带所选诗句的灯火动画。
- **Esc**：关闭移动端菜单。

## 视觉与人物优化

当前版本重点整理了人物与环境的接触关系：

- 人物素材按单格 **780 × 980** 的原始比例显示，不拉伸立绘。
- 补偿素材底部 8 像素透明边，脚底锚点与桥板、岸墙、木台顶面保持一致。
- 虹桥人物沿桥面缓步往返，逐帧使用拱桥切线计算落脚点，不再悬空或静止滑行。
- 行走时仅对下身施加轻幅交错摆动，上半身保持稳定，避免夸张变形。
- 桥面坡度会修正脚部局部高度；柔和接触阴影增强落地感。
- 站定人物不参与步态，减少动态模式下所有行人停在稳定姿态。
- 收敛夜间灯雾与桥灯光晕，让暖灯融入墨青夜色，避免过亮破坏留白。

```text
│   ├── styles.css             # 版式、章节、主题与响应式布局
│   └── atmosphere.css         # 灯雾、颗粒、视差与减少动态适配
└── js/
    ├── interface.js           # 中文文案、诗词、主题和界面交互
    ├── citizen-paths.js       # 行人 roster、往返路径与脚底坐标
    ├── citizens.js            # 人物实例渲染、步态和接触阴影

    ├── motion.js              # 指针和滚动产生的轻微 CSS 视差
    └── citizen-paths.test.js  # 人物路径与落地约束测试
```

## 实现说明

- **渲染**：Three.js 0.160.0，程序化城市与人物使用实例化几何体，水面包含镜像反射、波纹与灯光扰动。
- **运镜**：五章共享同一座连续城市，滚动进度驱动相机位置与注视点，而不是切换五张独立背景。
- **昼夜**：灯光、天空、雾色、水面、插图和界面文案联动切换。
- **性能**：限制像素比与粒子数量，移动端减少人物、船只、灯火等实例；低帧率时进一步降低渲染分辨率。
- **无障碍**：提供跳至正文、语义化导航、键盘焦点、状态播报与触控目标尺寸。
- **降级**：WebGL 不可用时显示静态画卷，章节阅读、诗词和导航仍可使用。

## 调试参数

可在地址后追加查询参数：

| 参数 | 用途 |
| --- | --- |
| `?motion=reduce` | 强制减少动态，关闭连续步态、视差与大部分动画 |
| `?noWebGL` | 模拟 WebGL 不可用，检查静态画卷降级 |
| `?capture` | 启用项目内置截图调试入口，仅供开发检查 |

也可直接访问章节锚点，例如 `http://localhost:4173/#bridge`。

## 测试与检查

在项目目录执行：

```bash
# 行人落点、桥面贴合、行走路径和站定状态
node js/citizen-paths.test.js

# JavaScript 语法检查
node --check js/interface.js
node --check js/citizen-paths.js
node --check js/citizens.js
node --check js/scene.js
node --check js/motion.js
```

建议发布前再手动检查：五章滚动、昼夜切换、两类放灯、诗笺点选、市集按钮、移动端菜单，以及系统的“减少动态”设置。

## 创作与出处

- 城市意象参考《清明上河图》，加入当代交互与艺术想象。
- 辛弃疾《青玉案·元夕》用于灯夜意境。
- 柳永《望海潮》原写杭州，本项目仅借其画桥与市井意象，不作为汴京实录。
- 孔明灯升空等画面属于艺术化表达。
